# ER Diagram

```mermaid
erDiagram
    spacecraft ||--o{ threshold_rule : "has"
    spacecraft ||--|{ spacecraft : "parent-child (unary)"
    data_item ||--|{ data_item_specialization : "specializes"
    app_user ||--|{ app_user_role : "specializes"
    threshold_rule ||--|| sensor : "belongs to"
    spacecraft ||--|| deployment_event : "has"
    telemetry_reading ||--|| sensor : "records"
    telemetry_reading ||--|| spacecraft : "belongs to"
    downlink_window ||--|| spacecraft : "covers"
    downlink_window ||--|| comm_mode : "uses"
    downlink_window ||--|| router_decision : "contains"
    router_decision ||--|| transmission : "triggers"
    transmission ||--|| data_item : "carries"
    alert ||--|| telemetry_reading : "generated by"
    command ||--|| spacecraft : "targets"
    volunteer ||--|| alert : "receives"
    
    spacecraft { pk spacecraft_id PK\n name VARCHAR\n deployer_id FK }
    threshold_rule { pk rule_id PK\n sensor_id FK\n rule_type VARCHAR\n min_val NUMERIC\n max_val NUMERIC }
    data_item { pk item_id PK\n type VARCHAR\n size_bytes INT\n urgency VARCHAR }
    data_item_specialization { pk item_id PK,Fk\n mode VARCHAR }
    app_user { pk user_id PK\n name VARCHAR\n role VARCHAR }
    app_user_role { pk role_id PK\n role_name VARCHAR }
    sensor { pk sensor_id PK\n name VARCHAR }
    telemetry_reading { pk reading_id PK\n sensor_id FK\n spacecraft_id FK\n value NUMERIC\n timestamp TIMESTAMP }
    downlink_window { pk window_id PK\n spacecraft_id FK\n capacity_kb INT\n snr_db NUMERIC\n status VARCHAR }
    comm_mode { pk mode_id PK\n name VARCHAR\n priority INT\n bitrate INT }
    router_decision { pk decision_id PK\n window_id FK\n item_id FK\n rationale TEXT }
    transmission { pk tx_id PK\n decision_id FK\n status VARCHAR }
    alert { pk alert_id PK\n reading_id FK\n message TEXT }
    command { pk cmd_id PK\n spacecraft_id FK\n action TEXT }
    volunteer { pk vol_id PK\n callsign VARCHAR }
```

**EER Features**
- Specialization of `data_item` and `app_user`
- Weak entity `threshold_rule`
- Unary relationship on `spacecraft`
